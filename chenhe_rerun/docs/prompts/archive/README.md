# Archived Prompts

This directory keeps historical prompt handoffs that mention old branches,
pre-cleanup report paths, or superseded method choices.

Do not use these as first-entry prompts for new work. Start from:

```text
docs/prompts/Prompt.md
docs/prompts/Prompt_language.md
docs/prompts/prompt_language_block_current_task.md
Report/language/wikitext103/order_teacher_distribution/head_signal_stability/current_distribution_methodology_summary.md
Report/language/wikitext103/mlp/distillation/README.md
```

If an archived prompt contains a useful idea, translate its paths into the
current `Report/language/wikitext103/...` layout and check it against the
current Fiedler distribution + MLP distillation summaries before acting.
