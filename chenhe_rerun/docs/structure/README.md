# Structure Index

Use this directory to answer "where does this live?" questions for the
language-focused repository.

## Files

- `PROJECT_STRUCTURE.md`
  Top-level language-only structure router.
- `PROJECT_STRUCTURE_language.md`
  WikiText103 layout, configs, scripts, reports, and caveats.

## Routing Rule

- WikiText103, block64, Laplacian/Fiedler distribution, EMA ablation, MLP
  distillation, or historical online spectral order:
  read `PROJECT_STRUCTURE_language.md`.
- Docs/report cleanup:
  read `PROJECT_STRUCTURE.md`, then `docs/organization/report_docs_layout.md`.

The previous non-language structure document was removed with the cleanup.
