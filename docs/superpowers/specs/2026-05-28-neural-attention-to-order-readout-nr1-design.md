# NR-1: Neural Attention-to-Order Readout (Distillation Pre-train)

**Date:** 2026-05-28
**Status:** design approved, ready for implementation plan
**Branch base:** `attn-order-alternating`

---

## 0. Where this fits

Part of the broader Attention-Order Flywheel line. Phase numbering follows the
"Neural Attention-to-Order Readout" roadmap (NR-1 ... NR-7) in the Attention-Order
design-decision record.

- NR-1 (this spec): **offline distillation pre-train**.
- NR-2 ... NR-7 (out of scope here): pairwise/transition labels, generalization
  tests, frozen plug-in eval, plug-in training, NLL fine-tune.

This spec covers NR-1 only. NR-2+ get their own specs after NR-1 lands.

---

## 1. Goal & scope

Train a readout `g_β: R^{N×N} → R^N` that takes only a per-sample attention
graph `B = A^T ∈ R^{64×64}` and outputs per-node scores `s_v`, with `σ̂ = argsort(-s)`.

The only first-stage claim:

> **Raw per-sample attention is sufficient to amortize the source-start C-D+L
> teacher's order into a one-shot neural readout.**

We **do not** claim:
- to beat C-D+L,
- to find an NLL-optimal order,
- to be free of hand-designed components,
- to be permutation-invariant.

### Supervision boundary (load-bearing)

NR-1 is an **attention-order matching** experiment, not an **NLL utility**
experiment. These are two different scientific questions and must not be
confused:

| Question | Setup |
|---|---|
| **NR-1 question:** can a neural readout recover the order structure encoded in attention? | label = attention-derived teacher order σ_T(B); train and gate only on agreement with σ_T |
| Distinct (future) question: which order minimizes frozen-θ NLL? | label = NLL ranking over orders; this is NR-7, not NR-1 |

Therefore NR-1 uses **no NLL, no oracle loss, no L2R / raster labels**. The
only supervision signal is the attention-derived teacher order. NLL appears
only as a secondary, post-hoc diagnostic in the report (§5.2) — never as a
training signal, never as a hard gate. Mixing NLL into NR-1 would invite the
critique: "you are not showing attention encodes order, you are using a loss
oracle to search orders." That confounder is excluded by construction.

### Crucial framing — graph-level mapping, not step-wise

Although the teacher order is generated by a sequential C-D+L rollout (which
internally uses `S_t, U_t, last`), **NR-1 treats the resulting order as a
graph-level target**. The student `g_β` is *not* given any rollout state and
must amortize the entire graph-to-order mapping into one pass:

```
   student:   g_β :  B            →  s ∈ R^N        →  σ̂ = argsort(-s)
   teacher:   T   :  B            →  σ_T            via sequential rollout
   target:    g_β(B) approximates σ_T(B)
```

NR-1 is NOT learning `(B, S_t, U_t, last) → q_t(v)`. That is a deliberate
weakening — it forces the student to summarize the graph into one global score
vector without a state-machine crutch.

### Stage interface

NR-1 is **offline distillation**. It does not touch the AOGPT main model `θ`.
No alternating training, no plug-in. The output is a trained `g_β` checkpoint
+ evaluation report.

## 2. Substrate and dataset

### 2.1 Substrate

- **Text only**, N = 64.
- Reuse `clean_base_random_perm` checkpoint, seed 42.
- **Train ckpt:** `block_lo_arm_order_network/probe_results/clean_base_random_perm/ckpt_step5000.pt`.
- **Cross-ckpt eval ckpts (diagnostic only):**
  `ckpt_step{10000,20000,30000,40000,50000,60000}.pt` from the same run dir.
- `block_perm.npy` and `inv_perm.npy` (clean_perm seed=42) are already saved
  in that dir. Reuse them.
- Cached `A_global_step{*}_seed42.npy` is available but not the input here
  (NR-1 uses **per-sample B**, not A_global; A_global only enters NR-1 as one
  of the four MVP ablations in §6).

### 2.2 Per-sample B extraction

- Forward `M` text contexts (64 blocks each) through the ckpt's AOGPT,
  capture the model's block-level attention `A_i ∈ R^{64×64}`.
- `B_i = A_i^T`, then `fill_diagonal(0)`.
- **Bug pre-req (blocker):** `extract_A_matrices` currently calls
  `torch.randperm` without seeding, so cross-run B extraction is not
  reproducible (see memory `cdl_evolution_clean_base_20260527`). Add an
  explicit seed argument and use it before this dataset gen.

### 2.3 Teacher

- **Name:** **CDL-source-start teacher** (NOT plain "C-D+L"). Text needs the
  source-start direction anchor — pure C-D+L can roll a reversed chain.
- Computed by `attn_order_teacher.rollout_order(B_i, mode='C-D+L',
  greedy=True, start=source(v))` where
  `source(v) = out(v) - α·in(v)`. **α value pre-req:** verify against the
  current alternating runtime config (`scripts/train_vq64_alternating.py`
  and related text alternating config) before running; do not silently
  pick a default. If the alternating runtime uses α = 0.5, use 0.5;
  otherwise match it.
- Output `σ_i ∈ S_{64}`. Per-node rank target: `r_T_i = inv_perm(σ_i)`,
  with **rank 0 = earliest revealed**.
- `pure-CDL` (no source-start) and `source-only` (readiness-only) are kept as
  *teacher ablations* in §6 — they are not the main label.

### 2.4 Two-tier dataset generation

| Tier | M graphs | Split | Use |
|---|---|---|---|
| **Smoke** | 1,000 | 800 train / 100 val / 100 test | sanity check: loss goes down, τ non-random, no rank-convention bugs |
| **Full** | 10,000 | 8,000 / 1,000 / 1,000 | MVP metrics |

**Order:** smoke first, sign off on smoke before generating full. Attention
extraction is the dominant cost; spending it on a wrong label/direction would
be the most expensive bug.

Cross-ckpt eval: 1,000 per held-out ckpt, generated only after smoke passes.

## 3. Architecture

```
# Per-node input feature
x_v = concat(B[v, :], B[:, v])         # R^{2N} = R^{128}
H_0 = Linear(2N, d_model)(x_v)         # d_model = 64
H_L = TransformerEncoder(
        H_0,
        layers=2, heads=4, ffn=4*d_model,
        no positional embedding
      )
s_v = Linear(d_model, 1)(H_L[v])       # scalar per node
σ̂  = argsort(-s)
```

- 64 node tokens, **no extra positional embedding added**.
- Params ≈ 50–80K, same order of magnitude as the current 12-d MLP.

### Honest framing of equivariance

This is **not** a fully permutation-invariant model. Even without a node
positional embedding, the per-node feature `x_v = [B[v,:], B[:,v]]` carries
the row/column coordinates of `B`, and those coordinates encode node identity
through the fixed slot ordering of the graph. We keep it that way because
clean_perm + model slots already define a fixed graph coordinate system, and
making the readout strictly equivariant would require edge-list / message-
passing / edge-bias-attention machinery that NR-1 deliberately avoids.

We call this a **low-extra-position-bias readout**, not a
permutation-invariant readout. This phrasing must be used consistently in
later writeups.

## 4. Loss

### 4.1 Main loss: pairwise logistic

```
L_pair = - (1 / |P|) Σ_{(i,j) ∈ P} log σ( s_i − s_j )
P      = { (i, j) : r_T(i) < r_T(j) }
```

**Rank convention (write into code as a constant, with assertion):**

- `rank 0 = earliest revealed node`
- `r_T(i) < r_T(j)` ⟹ node `i` revealed earlier ⟹ should score **higher** ⟹ `s_i > s_j`.

For N = 64, |P| = 64·63/2 = 2,016. Use **all pairs** per graph; subsampling is
a fallback only if this turns out memory-bound (it should not).

### 4.2 Auxiliary loss: rank L2 (diagnostic only, off by default)

```
L_rank_L2 = || s − (N − 1 − r_T) ||²
```
(`N − 1 − r_T` puts earliest at the largest target value, consistent with
the convention above.)

Reported as a sanity-check number, not part of the main objective.

## 5. Evaluation

### 5.1 MVP hard gates — attention-order matching only

NR-1 passes only if **all** of the following hold on **same-ckpt held-out val**.
All three are attention-order matching metrics; no NLL appears here.

| Metric | Hard gate |
|---|---|
| Kendall τ(σ̂, σ_T) | ≥ 0.80 |
| Pairwise precedence accuracy | ≥ 0.90 |
| Spearman ρ(ŝ, r_T) | ≥ 0.85 |

Pairwise precedence accuracy = fraction of node pairs `(i, j)` for which
`r_T(i) < r_T(j) ⇒ ŝ_i > ŝ_j`. For N = 64 with all 2,016 pairs, this is
numerically near-identical to `(1 + τ)/2`; we list both because they are the
canonical names reviewers expect (τ for rank, pairwise accuracy for
precedence). Spearman ρ gives a distinct, rank-correlation angle.

All gates are on the **same-ckpt held-out val**, not on cross-ckpt data.

### 5.2 Diagnostic metrics (NOT pass/fail; reported only)

| Metric | Used for |
|---|---|
| top-1 first-node match | did the student inherit the source-start anchor? |
| first-3 set match | early-order quality |
| τ on cross-ckpt 10k/20k/30k/40k/50k/60k | NR-4 generalization (NOT NR-1 gate) |
| **frozen-θ NLL gap** vs teacher | utility check, **NOT a gate** — never used to select g_β |
| frozen-θ NLL on cross-ckpt (freeze at each cross ckpt) | stage-shift utility, diagnostic |

The frozen-θ NLL is described in detail because it is the post-hoc utility
diagnostic, but to repeat: it is **not** a training signal, **not** a model
selection criterion, **not** a hard gate. Concretely: freeze the 5k ckpt's
main model `θ`, take `σ̂` (resp. `σ_T`) as the reveal order on the same
held-out val batch, compute the mean per-token NLL under each order, report
`NLL(σ̂) − NLL(σ_T)`. Single forward pass per order per sample.

Reasoning for these choices:
- τ can be high while top-1 misses an equivalent starting node — top-1 is too
  brittle as a gate.
- Source-start makes top-1 nearly deterministic for the *teacher*, so high
  student top-1 mainly demonstrates source-anchor inheritance, not order
  quality.
- Cross-ckpt drop is **expected and not a failure**; it justifies refresh /
  finetune in the alternating flywheel (NR-4 / NR-6). If cross-ckpt τ is
  bad, the conclusion is "must refresh g_β per round," not "NR-1 failed."
- If τ ≥ 0.80 but frozen-θ NLL gap is large, the conclusion is
  **"imitation succeeds, utility is not guaranteed"** — that gap is the
  empirical wedge that motivates NR-5 (frozen plug-in utility) and NR-7
  (NLL/ranking fine-tune). It is **not** a failure of NR-1.

## 6. MVP ablations (in scope)

Exactly four. All run only after the main gates pass.

| Ablation | What it tests | Expected (text) |
|---|---|---|
| **B → B^T (reverse)** | direction matters? | scores invert; τ flips sign |
| **B → (B + B^T) / 2 (sym)** | directedness matters? | τ drops significantly |
| **row-shuffle B** | pairwise topology matters? | τ barely drops (text load-bearing signal is in-out readiness, not pairwise topology) |
| **B_i vs B_global (static)** | static slot prior vs per-sample dynamic? | if B_global alone hits τ ≥ 0.80, static slot prior dominates → dynamic claim weakens |

Each ablation is a single training run with the same data + same hyperparams,
only the input transform changes.

---

## 7. Out of scope (must NOT do in NR-1)

- Plug-in into the alternating training loop (`α`, refresh, source-start
  schedule) — that is NR-5 / NR-6.
- **Any use of NLL as a training signal, label, or gate.** NLL appears only
  as a §5.2 diagnostic. NLL-based supervision is NR-7 only and must be
  named explicitly when it is introduced ("NLL-supervised /
  reward-refined controller").
- L2R, raster, or any oracle order as a label — NR-1 supervision is the
  attention-derived teacher order, nothing else.
- Image substrate (patch2x2 or any other) — covered after text proof-of-concept.
- Pairwise-precedence label, transition-matrix label — NR-2.
- Flatten-MLP, CNN-Mixer, or any architecture sweep — NR-3.
- C-only / D-only / L-only teacher component ablation — that is teacher
  analysis, not NR-1 readout analysis.
- Adding positional embeddings or edge-bias attention machinery — would
  defeat the "low-extra-position-bias" framing.

## 8. Implementation outline (handed to writing-plans)

1. **Pre-req fix.** Add explicit seed argument to `extract_A_matrices`
   (currently relies on un-seeded `torch.randperm`), and confirm
   bit-identical B extraction across two runs with the same seed.
2. **Smoke dataset (1k).** Forward 1,000 text contexts through 5k ckpt;
   save `B_i` (float16) and teacher `σ_i` (int8); store
   `r_T_i = inv_perm(σ_i)` alongside.
3. **`g_β` module.** New file
   `block_lo_arm_order_network/neural_readout/graph_transformer_readout.py`.
   Implement input projection, `nn.TransformerEncoder(d_model=64, nhead=4,
   num_layers=2)`, scalar head. No positional embeddings. ~80 lines.
4. **Training loop.** New file
   `block_lo_arm_order_network/neural_readout/train_nr1.py`. Pairwise
   logistic loss (all 2,016 pairs per graph), AdamW, ~10 epochs on smoke.
   Log: train/val loss, Kendall τ, Spearman ρ, top-1 match, first-3 match,
   per-epoch.
5. **Frozen-θ NLL eval (offline diagnostic, NOT a gate).** New file
   `block_lo_arm_order_network/neural_readout/eval_nr1_frozen_nll.py`.
   Loads 5k ckpt + g_β, computes `NLL(σ̂) − NLL(σ_T)` over held-out val
   with a single forward pass per order. Output goes into the report
   §5.2 diagnostics; the number does **not** select g_β and does
   **not** participate in pass/fail.
6. **Sanity check on smoke.** Confirm loss decreases, val τ non-random
   (≥ 0.5 ish), no rank-convention bug. If yes, generate full 10k dataset
   and re-train.
7. **MVP gate run.** Train on full 10k, report against §5.1 gates.
8. **Cross-ckpt eval.** Extract 1,000 (B, σ_T) pairs per held-out ckpt;
   evaluate frozen g_β. Diagnostic-only.
9. **Four MVP ablations** (§6) on full 10k. Each is a separate training run.
10. **Report.** One markdown report under
    `analyses/neural_readout_nr1_<date>/REPORT.md` summarizing gates +
    diagnostic metrics + four ablations.

writing-plans will turn this into a TDD-style execution plan with explicit
checkpoints between steps 6 ↔ 7 and 7 ↔ 9.

## 9. Risks and named failure modes

| Risk | What it would look like | Reading |
|---|---|---|
| **τ low** | training loss flat or val τ ≈ random | model can't do the mapping at all from raw B — try architecture change (NR-3) |
| **τ high, frozen-θ NLL gap large** | rank agreement but downstream order quality bad | "Imitation succeeds, utility is not guaranteed." This is **not** an NR-1 failure — NR-1's job is attention-order matching, which has succeeded. The NLL gap is the empirical wedge that motivates NR-5 (frozen plug-in utility) and NR-7 (NLL/ranking fine-tune). Report it, do not retrain to chase it. |
| **B_global ablation hits τ ≥ 0.80** | static slot prior dominates | per-sample dynamic signal is weak in text — focus future claims on directed readiness + slot geometry, not per-sample attention dynamism. Honest finding. |
| **row-shuffle ablation barely drops τ** | text readout is readiness, not pairwise | consistent with the design-decision record §2. Reinforce that text vs image readouts read different signals. |
| **cross-ckpt τ collapses** | g_β specific to ckpt stage | reframe NR-1 product as a "per-round refreshable" readout — flywheel-compatible by design. |
| **`torch.randperm` seeding fix breaks downstream** | extraction signature change ripples | scoped change; touch only the extraction call site and confirm via two-run bit-identity test. |

## 10. Honest claims after NR-1 lands

If gates pass:

> A small graph-attention readout, with no rollout state, recovers the order
> structure encoded by the source-start C-D+L teacher from raw per-sample
> attention graphs at the 5k checkpoint of a random-permutation-trained
> any-order text model. The hand-designed attention-to-order mapping can be
> amortized into a single neural pass. This does not yet show that learned
> readouts beat hand readouts, nor that the imitated order is NLL-optimal —
> those are NR-5 and NR-7 questions.

If gates pass but the diagnostic frozen-θ NLL gap is large: claim only what
NR-1 actually shows ("imitation succeeded, utility is not guaranteed"), and
explicitly defer the utility question to NR-5 / NR-7. Do not retrain g_β
to chase NLL — that would silently turn NR-1 into NR-7 and break the
supervision boundary in §1.

If gates fail: reduce scope (smaller M for sanity), or relax the readout to
include B_global as an input (Strategy B fallback), or escalate to NR-3
architecture variants. Do not redefine the gates after seeing the numbers,
and in particular do not add NLL into the gates.
